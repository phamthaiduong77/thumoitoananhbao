Cấu Hình Kết Nối Supabase

Nếu chưa cấu hình, dữ liệu sẽ tự động lưu vào LocalStorage máy khách.

Mẫu SQL tạo bảng trong Supabase SQL Editor:

create table rsvps (
  id bigint generated by default as identity primary key,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null,
  name text,
  status text,
  guests int,
  message text
);
